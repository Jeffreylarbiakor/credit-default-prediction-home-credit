# Credit Default Prediction — Home Credit Default Risk

End-to-end credit scoring model on the Home Credit Default Risk dataset
([Kaggle competition link](https://www.kaggle.com/competitions/home-credit-default-risk)).

**Status: in progress.** Notebooks, evaluation, and SHAP interpretation
landing over the next 1-2 days.

## Planned structure
- `01_eda.ipynb` — Exploratory data analysis
- `02_feature_engineering.ipynb` — Feature engineering and class-imbalance handling
- `03_modeling.ipynb` — Logistic regression, random forest, LightGBM
- `04_evaluation.ipynb` — ROC-AUC, PR-AUC, calibration, threshold-based business framing
- `05_interpretation.ipynb` — SHAP-based interpretation
